# Lighting Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the four fixed directional shade constants with flood-filled skylight, smooth per-vertex light and ambient occlusion, a day/night cycle, and a camera-mounted flashlight.

**Architecture:** A single world-wide `NativeU8Arr` skylight field (128x256x128, one byte per voxel, 0..15) lives as a direct field of `World`. A column seed pass plus a 6-neighbour BFS fills it; block edits repair it with an add/remove incremental pass. The mesher reads that field to compute per-vertex light and AO, packs both into the greedy mask key, and emits an 8-float vertex whose new `face` attribute drives a normal and directional-shade lookup in the shader. Day/night and the flashlight are shader uniforms and touch no voxel data.

**Tech Stack:** March (`forge check` / `build` / `lint --strict` / `test`), the `cf_shim.c` C shim, OpenGL 3.3 core, GLFW.

## Global Constraints

- `forge check` clean, `forge lint --strict` clean, `forge test` green. Baseline before this plan: **25 tests, 0 failures**; one pre-existing warning (`chunk.march:19` unused `sy`) that is not ours to fix.
- **`&&` does not short-circuit** (GAPS.md G33). A bounds test guarding an array access MUST be a separate nested `if`, never an `&&` conjunct. `||` over pure comparisons is fine.
- Hot loops carry `@[no_alloc]`, consistent with the existing frame path.
- **No aggregate returns in hot loops.** Returning a two-field variant allocates. When a loop must thread two mutable arrays, either split it into two single-return passes, or pack scalar state into the tail of the array itself — the `Mesher.fill_mask` idiom, which stores its count at `mask[256]`.
- Recursion, not loops. `pfn` for private helpers, `fn` for the module surface, `doc "..."` on the public surface.
- No new dependencies. `native/cf_shim.c` stays the only unsafe surface.
- World geometry is fixed at `World.size() = 8` chunks, i.e. **128 x 256 x 128 = 4,194,304 voxels**. Flat world index is `x + 128 * (z + 128 * y)`.

## Deviation from the spec

`docs/superpowers/specs/2026-09-03-lighting-design.md` §1 puts the light array inside `Chunk`. **This plan does not.** A per-chunk light array lives inside `World`'s `Array.PVec`, so it is shared and `NativeArray.set_u8` cannot write in place (GAPS.md G54, already documented in `chunk_mesh.march`); every BFS write would allocate a new `Chunk` variant plus an `Array.set`. One world-wide array held as a direct field of `World` avoids that, matches the world-space index the spec already chose for the BFS, gives the mesher one extra argument instead of five, and removes the G28-G30 aggregate-RC risk that §1 flagged. The spec's §1 and §6-step-1 are superseded by Task 4 here; everything else in the spec stands.

```march
-- Light — the world skylight field: one byte per voxel, value 0..15, in a
-- single flat NativeU8Arr of 128 * 256 * 128. Index x + 128 * (z + 128 * y),
-- the same world-space coordinates World uses.
--
-- One array for the whole world, not one per chunk: a per-chunk array lives
-- inside World's Array.PVec and is therefore shared, so NativeArray.set_u8
-- could never write in place (GAPS.md G54) and every BFS write would allocate.
--
-- The BFS queue is a ring buffer over a NativeIntArr whose head and tail live
-- in the two slots past the ring (the Mesher.fill_mask idiom), so the hot loop
-- threads one value and returns one value — no aggregate, no allocation.
mod CubeForge.Light do

  alias CubeForge.Chunk as C

  fn size_x() : Int do 128 end
  fn size_y() : Int do 256 end
  fn size_z() : Int do 128 end
  fn volume() : Int do 4194304 end
  fn max_level() : Int do 15 end

  doc "Flat world index of a voxel; the refinements let Z3 discharge the bound."
  @[no_alloc]
  fn index(x : {Int | 0 <= _ && _ < 128}, y : {Int | 0 <= _ && _ < 256}, z : {Int | 0 <= _ && _ < 128})
      : {Int | 0 <= _ && _ < 4194304} do
    x + 128 * (z + 128 * y)
  end

  doc "A dark light field."
  fn new() : NativeU8Arr do NativeArray.make_u8(4194304, 0) end

  doc "Light at a world coordinate; 0 outside the world."
  @[no_alloc]
  fn get(la : NativeU8Arr, x : Int, y : Int, z : Int) : Int do
    if x < 0 || x >= 128 || y < 0 || y >= 256 || z < 0 || z >= 128 do 0
    else NativeArray.get_u8(la, index(x, y, z)) end
  end

  doc "Light absorbed per step by a voxel of block [id]: 0 air, 2 water, 15 (total) otherwise."
  @[no_alloc]
  fn opacity(id : Int) : Int do
    if id == 0 do 0
    else if C.is_water(id) do 2
    else max_level() end end
  end

  @[no_alloc]
  fn is_opaque(id : Int) : Bool do opacity(id) >= max_level() end

  -- ── BFS queue: ring buffer, head/tail packed past the ring ────────────────
  -- Capacity is the frontier bound, not the visited-set bound. The widest
  -- skylight frontier is a few 128x128 layers (~16k entries); 2^20 is ample.

  fn q_cap() : Int do 1048576 end

  doc "An empty BFS queue."
  fn queue_new() : NativeIntArr do NativeArray.make_int(1048578, 0) end

  @[no_alloc] fn q_head(q : NativeIntArr) : Int do NativeArray.get_int(q, 1048576) end
  @[no_alloc] fn q_tail(q : NativeIntArr) : Int do NativeArray.get_int(q, 1048577) end
  @[no_alloc] fn q_empty(q : NativeIntArr) : Bool do q_head(q) == q_tail(q) end
  @[no_alloc] fn q_len(q : NativeIntArr) : Int do (q_tail(q) - q_head(q) + 1048576) % 1048576 end

  doc "Push one entry. Overwrites the oldest entry if the ring is full."
  @[no_alloc]
  fn q_push(q : NativeIntArr, v : Int) : NativeIntArr do
    let t = q_tail(q)
    NativeArray.set_int(NativeArray.set_int(q, t, v), 1048577, (t + 1) % 1048576)
  end

  @[no_alloc] fn q_peek(q : NativeIntArr) : Int do NativeArray.get_int(q, q_head(q)) end
  @[no_alloc]
  fn q_pop(q : NativeIntArr) : NativeIntArr do
    NativeArray.set_int(q, 1048576, (q_head(q) + 1) % 1048576)
  end

  doc "Drop every entry without reallocating."
  @[no_alloc]
  fn q_clear(q : NativeIntArr) : NativeIntArr do
    NativeArray.set_int(NativeArray.set_int(q, 1048576, 0), 1048577, 0)
  end

end
```

### Task 2: Column seeding

Sunlight enters from `y = 255` and walks down each `(x, z)` column, losing `opacity(id)` per voxel and stopping at the first opaque block. Air holds a shaft at full 15 all the way down; water dims it 2 per voxel. Every seeded voxel is enqueued so Task 3's spread can carry light sideways under overhangs.

**Files:**
- Modify: `lib/cube_forge/light.march`
- Test: `test/light_test.march`

**Interfaces:**
- Consumes: Task 1's `index/3`, `get/4`, `opacity/1`, `is_opaque/1`, `q_push/2`, `queue_new/0`. `CubeForge.World.block_at/4` (already `@[no_alloc]`, returns 0 outside the world).
- Produces: `Light.seed_column/6 : NativeU8Arr`, `Light.seed_column_q/6 : NativeIntArr`, `Light.seed_all/3 : NativeU8Arr`, `Light.seed_all_q/3 : NativeIntArr`.

Note the split-pass shape required by the Global Constraints: `seed_column` returns only the light array, `seed_column_q` returns only the queue, and each re-derives the same decision. Doing the opacity walk twice is two integer compares per voxel and keeps both hot loops free of aggregate returns.

  -- ── Seeding: sunlight down each column ────────────────────────────────────

  -- Light level a column reaches at [y], given it arrived at y+1 carrying [lv].
  -- Returns 0 once the column is blocked or fully absorbed.
  @[no_alloc]
  pfn column_step(w : CubeForge.World.World, x : Int, y : Int, z : Int, lv : Int) : Int do
    let id = CubeForge.World.block_at(w, x, y, z)
    if is_opaque(id) do 0
    else
      let l = lv - opacity(id)
      if l <= 0 do 0 else l end
    end
  end

  pfn seed_column_go(la : NativeU8Arr, w : CubeForge.World.World, x : Int, z : Int, y : Int, lv : Int) : NativeU8Arr do
    if y < 0 do la
    else
      let l = column_step(w, x, y, z, lv)
      if l <= 0 do la
      else seed_column_go(NativeArray.set_u8(la, index(x, y, z), l), w, x, z, y - 1, l) end
    end
  end

  doc "Seed the sunlight column at (x, z) into [la], writing from y = 255 down."
  fn seed_column(la : NativeU8Arr, w : CubeForge.World.World, x : Int, z : Int, y : Int, lv : Int) : NativeU8Arr do
    seed_column_go(la, w, x, z, y, lv)
  end

  pfn seed_column_q_go(q : NativeIntArr, w : CubeForge.World.World, x : Int, z : Int, y : Int, lv : Int) : NativeIntArr do
    if y < 0 do q
    else
      let l = column_step(w, x, y, z, lv)
      if l <= 0 do q
      else seed_column_q_go(q_push(q, index(x, y, z)), w, x, z, y - 1, l) end
    end
  end

  doc "Enqueue the same voxels seed_column writes, for the spread pass."
  fn seed_column_q(q : NativeIntArr, w : CubeForge.World.World, x : Int, z : Int, y : Int, lv : Int) : NativeIntArr do
    seed_column_q_go(q, w, x, z, y, lv)
  end

  pfn seed_all_go(la : NativeU8Arr, w : CubeForge.World.World, i : Int) : NativeU8Arr do
    if i >= 16384 do la
    else seed_all_go(seed_column_go(la, w, i % 128, i / 128, 255, max_level()), w, i + 1) end
  end

  doc "Seed every column of the world. [i0] is the first column index (0 for a full pass)."
  fn seed_all(la : NativeU8Arr, w : CubeForge.World.World, i0 : Int) : NativeU8Arr do
    seed_all_go(la, w, i0)
  end

  pfn seed_all_q_go(q : NativeIntArr, w : CubeForge.World.World, i : Int) : NativeIntArr do
    if i >= 16384 do q
    else seed_all_q_go(seed_column_q_go(q, w, i % 128, i / 128, 255, max_level()), w, i + 1) end
  end

  doc "Enqueue every voxel seed_all writes."
  fn seed_all_q(q : NativeIntArr, w : CubeForge.World.World, i0 : Int) : NativeIntArr do
    seed_all_q_go(q, w, i0)
  end

### Task 3: BFS spread

Carries light sideways and under overhangs. Pop a voxel at level `L`; each of six neighbours that would receive more than it currently has takes `L - 1 - opacity(neighbour)` and is enqueued.

**Files:**
- Modify: `lib/cube_forge/light.march`
- Test: `test/light_test.march`

**Interfaces:**
- Consumes: Task 1 and 2's surface.
- Produces: `Light.spread/3 : NativeU8Arr`, `Light.enqueue_lit/2 : NativeIntArr`, `Light.flood/2 : NativeU8Arr`.

The queue-capacity constraint from Task 2 shapes this: a full flood cannot enqueue all 4.2M seeded voxels. Instead `flood` seeds the columns, then builds the initial frontier with `enqueue_lit`, which enqueues only voxels that have light *and* at least one neighbour that could still receive more. That frontier is bounded by the terrain surface area, comfortably inside the ring.

- [ ] **Step 3: Write the implementation**

```march
  -- ── Spread: 6-neighbour BFS ───────────────────────────────────────────────

  -- The level a neighbour at (x, y, z) receives from a voxel at level [l].
  @[no_alloc]
  pfn to_neighbor(w : CubeForge.World.World, l : Int, x : Int, y : Int, z : Int) : Int do
    let id = CubeForge.World.block_at(w, x, y, z)
    if is_opaque(id) do 0 else l - 1 - opacity(id) end
  end

  -- Write [nl] at (x, y, z) when it is brighter than what is already there.
  @[no_alloc]
  pfn write_brighter(la : NativeU8Arr, x : Int, y : Int, z : Int, nl : Int) : NativeU8Arr do
    if nl <= 0 do la
    else if x < 0 || x >= 128 || y < 0 || y >= 256 || z < 0 || z >= 128 do la
    else if nl <= NativeArray.get_u8(la, index(x, y, z)) do la
    else NativeArray.set_u8(la, index(x, y, z), nl) end end end
  end

  -- Enqueue (x, y, z) when write_brighter just landed [nl] there and it can
  -- still propagate. Re-deriving the test avoids an aggregate return.
  @[no_alloc]
  pfn enq_written(la : NativeU8Arr, q : NativeIntArr, x : Int, y : Int, z : Int, nl : Int) : NativeIntArr do
    if nl <= 1 do q
    else if x < 0 || x >= 128 || y < 0 || y >= 256 || z < 0 || z >= 128 do q
    else if NativeArray.get_u8(la, index(x, y, z)) != nl do q
    else q_push(q, index(x, y, z)) end end end
  end

  -- One popped voxel's six neighbour writes.
  @[no_alloc]
  pfn spread_writes(la : NativeU8Arr, w : CubeForge.World.World, x : Int, y : Int, z : Int, l : Int) : NativeU8Arr do
    let a1 = write_brighter(la, x + 1, y, z, to_neighbor(w, l, x + 1, y, z))
    let a2 = write_brighter(a1, x - 1, y, z, to_neighbor(w, l, x - 1, y, z))
    let a3 = write_brighter(a2, x, y + 1, z, to_neighbor(w, l, x, y + 1, z))
    let a4 = write_brighter(a3, x, y - 1, z, to_neighbor(w, l, x, y - 1, z))
    let a5 = write_brighter(a4, x, y, z + 1, to_neighbor(w, l, x, y, z + 1))
    write_brighter(a5, x, y, z - 1, to_neighbor(w, l, x, y, z - 1))
  end

  -- The matching six enqueues, run after spread_writes on the same voxel.
  @[no_alloc]
  pfn spread_enqueues(la : NativeU8Arr, q : NativeIntArr, w : CubeForge.World.World, x : Int, y : Int, z : Int, l : Int) : NativeIntArr do
    let q1 = enq_written(la, q, x + 1, y, z, to_neighbor(w, l, x + 1, y, z))
    let q2 = enq_written(la, q1, x - 1, y, z, to_neighbor(w, l, x - 1, y, z))
    let q3 = enq_written(la, q2, x, y + 1, z, to_neighbor(w, l, x, y + 1, z))
    let q4 = enq_written(la, q3, x, y - 1, z, to_neighbor(w, l, x, y - 1, z))
    let q5 = enq_written(la, q4, x, y, z + 1, to_neighbor(w, l, x, y, z + 1))
    enq_written(la, q5, x, y, z - 1, to_neighbor(w, l, x, y, z - 1))
  end
```

The two mutable arrays still have to advance together across the pop loop. Drive them as a pair of alternating single-return passes over one popped entry at a time:

```march
  pfn spread_go(la : NativeU8Arr, q : NativeIntArr, w : CubeForge.World.World, budget : Int) : NativeU8Arr do
    if budget <= 0 do la
    else if q_empty(q) do la
    else
      let i = q_peek(q)
      let x = i % 128
      let z = (i / 128) % 128
      let y = i / 16384
      let l = NativeArray.get_u8(la, i)
      if l <= 1 do spread_go(la, q_pop(q), w, budget - 1)
      else
        let la1 = spread_writes(la, w, x, y, z, l)
        let q1 = spread_enqueues(la1, q_pop(q), w, x, y, z, l)
        spread_go(la1, q1, w, budget - 1)
      end
    end end
  end

  doc "Drain [q], propagating light into [la]. [budget] bounds the pops (-1 for unbounded)."
  fn spread(la : NativeU8Arr, q : NativeIntArr, w : CubeForge.World.World) : NativeU8Arr do
    spread_go(la, q, w, -1)
  end
```

`budget <= 0` with `-1` never fires, so `-1` means unbounded; keep the parameter because Task 5 wants a bounded variant for the incremental path.

Then the initial frontier and the full flood:

```march
  -- A lit voxel belongs on the frontier when some neighbour is darker than
  -- what this voxel could give it.
  @[no_alloc]
  pfn is_frontier(la : NativeU8Arr, w : CubeForge.World.World, x : Int, y : Int, z : Int, l : Int) : Bool do
    if l <= 1 do false
    else
      if get(la, x + 1, y, z) < to_neighbor(w, l, x + 1, y, z) do true
      else if get(la, x - 1, y, z) < to_neighbor(w, l, x - 1, y, z) do true
      else if get(la, x, y + 1, z) < to_neighbor(w, l, x, y + 1, z) do true
      else if get(la, x, y - 1, z) < to_neighbor(w, l, x, y - 1, z) do true
      else if get(la, x, y, z + 1) < to_neighbor(w, l, x, y, z + 1) do true
      else get(la, x, y, z - 1) < to_neighbor(w, l, x, y, z - 1) end end end end end
    end
  end

  pfn enqueue_lit_go(la : NativeU8Arr, q : NativeIntArr, w : CubeForge.World.World, i : Int) : NativeIntArr do
    if i >= 4194304 do q
    else
      let l = NativeArray.get_u8(la, i)
      if l <= 1 do enqueue_lit_go(la, q, w, i + 1)
      else if is_frontier(la, w, i % 128, i / 16384, (i / 128) % 128, l) do
        enqueue_lit_go(la, q_push(q, i), w, i + 1)
      else enqueue_lit_go(la, q, w, i + 1) end end
    end
  end

  doc "Enqueue every lit voxel that still has a darker neighbour to give to."
  fn enqueue_lit(la : NativeU8Arr, w : CubeForge.World.World) : NativeIntArr do
    enqueue_lit_go(la, queue_new(), w, 0)
  end

  doc "Compute the world's skylight from scratch: seed every column, then spread."
  fn flood(w : CubeForge.World.World, _unused : Int) : NativeU8Arr do
    let la = seed_all(new(), w, 0)
    spread(la, enqueue_lit(la, w), w)
  end
```

### Task 5: Incremental relight

The correctness centrepiece. A block edit must repair the field without a full re-flood.

**Files:**
- Modify: `lib/cube_forge/light.march`
- Test: `test/light_test.march`

**Interfaces:**
- Consumes: everything from Tasks 1-4.
- Produces: `Light.relight_at/5 : NativeU8Arr` (light array, world *after* the edit, x, y, z), and `World.relight_at/4 : World`.

**Algorithm.** On an edit at `p`:

- **Darkening** (the block became more opaque, or a sky column was capped). Run a removal pass seeded with `(p, oldLight)`. Pop `(i, ol)`; for each neighbour `n` at level `nl`: when `nl != 0` and `nl < ol`, `n` was lit by us — push `(n, nl)` onto the removal queue and zero it. When `nl >= ol`, `n` survives on its own light — push `n` onto the addition queue as a re-seed. When removal drains, re-seed the affected column (a capped shaft darkens everything below), then run `spread` on the addition queue.
- **Brightening** (the block became less opaque). Addition only: re-run `seed_column` from `p` downward in case a sky shaft opened, enqueue `p` and its six neighbours, and `spread`.

Both cases end in `spread`, so the only new machinery is the removal pass. Removal needs `(index, level)` pairs; push two ints per entry and pop them in pairs.

- [ ] **Step 3: Write the implementation**

```march
  -- ── Incremental relight ───────────────────────────────────────────────────
  -- Removal entries are (index, level) pairs: two pushes, two pops.

  @[no_alloc]
  pfn rm_push(q : NativeIntArr, i : Int, l : Int) : NativeIntArr do q_push(q_push(q, i), l) end

  -- Zero every neighbour that was lit by a voxel at level [ol], enqueueing it
  -- for further removal; neighbours that are at least as bright survive and go
  -- on the addition queue instead.
  @[no_alloc]
  pfn remove_writes(la : NativeU8Arr, x : Int, y : Int, z : Int, ol : Int) : NativeU8Arr do
    let a1 = rm_one(la, x + 1, y, z, ol)
    let a2 = rm_one(a1, x - 1, y, z, ol)
    let a3 = rm_one(a2, x, y + 1, z, ol)
    let a4 = rm_one(a3, x, y - 1, z, ol)
    let a5 = rm_one(a4, x, y, z + 1, ol)
    rm_one(a5, x, y, z - 1, ol)
  end

  @[no_alloc]
  pfn rm_one(la : NativeU8Arr, x : Int, y : Int, z : Int, ol : Int) : NativeU8Arr do
    if x < 0 || x >= 128 || y < 0 || y >= 256 || z < 0 || z >= 128 do la
    else
      let nl = NativeArray.get_u8(la, index(x, y, z))
      if nl == 0 do la
      else if nl < ol do NativeArray.set_u8(la, index(x, y, z), 0)
      else la end end
    end
  end
```

The removal pass has three arrays in flight (light, removal queue, addition queue), which no single-return pass can thread. Resolve it the same way as `spread`: split into per-neighbour passes that each return one array and re-derive their decision from the light array's state. Because `rm_one` zeroes a neighbour only when `nl < ol`, the enqueue pass must run *before* the write pass for the removal queue (it needs the pre-zero level) and *after* it for the addition queue. Order each popped entry as:

1. `rq1 = remove_enqueues(la, rq, x, y, z, ol)` — reads pre-zero levels, pushes `(n, nl)` pairs.
2. `aq1 = add_enqueues(la, aq, x, y, z, ol)` — reads pre-zero levels, pushes surviving `n`.
3. `la1 = remove_writes(la, x, y, z, ol)` — zeroes.

Then:

```march
  pfn remove_go(la : NativeU8Arr, rq : NativeIntArr, aq : NativeIntArr, w : CubeForge.World.World) : NativeU8Arr do
    if q_empty(rq) do la
    else
      let i = q_peek(rq)
      let rq1 = q_pop(rq)
      let ol = q_peek(rq1)
      let rq2 = q_pop(rq1)
      let x = i % 128
      let z = (i / 128) % 128
      let y = i / 16384
      let rq3 = remove_enqueues(la, rq2, x, y, z, ol)
      let aq1 = add_enqueues(la, aq, x, y, z, ol)
      let la1 = remove_writes(la, x, y, z, ol)
      remove_go(la1, rq3, aq1, w)
    end
  end
```

`remove_go` returns only the light array, so the addition queue it accumulated is lost. Rebuild it after removal drains with `enqueue_lit`, which recomputes exactly the frontier the addition pass needs — correct, and it removes the third array entirely:

```march
  doc "Repair the skylight field after the block at (x, y, z) changed. [w] is the world after the edit."
  fn relight_at(la : NativeU8Arr, w : CubeForge.World.World, x : Int, y : Int, z : Int) : NativeU8Arr do
    let ol = get(la, x, y, z)
    -- Darken: clear this voxel and everything it was lighting, plus the column
    -- beneath it in case a sky shaft was just capped.
    let la1 = if ol > 0 do remove_go(NativeArray.set_u8(la, index(x, y, z), 0), rm_push(queue_new(), index(x, y, z), ol), queue_new(), w)
              else la end
    let la2 = clear_column(la1, x, z, y)
    -- Re-seed the column from the top and spread from the surviving frontier.
    let la3 = seed_column(la2, w, x, z, 255, max_level())
    spread(la3, enqueue_lit(la3, w), w)
  end

  -- Zero the column at (x, z) from y downward, so a newly capped shaft does not
  -- keep stale light beneath it.
  pfn clear_column(la : NativeU8Arr, x : Int, z : Int, y : Int) : NativeU8Arr do
    if y < 0 do la
    else clear_column(NativeArray.set_u8(la, index(x, y, z), 0), x, z, y - 1) end
  end
```

**Be honest about the cost here:** `enqueue_lit` scans all 4.2M voxels, so this `relight_at` is *not* incremental in the sense the spec promised — it is a full scan plus a bounded spread. Get it **correct first** with this shape and the property test green, then optimise in Step 5 below by replacing the `enqueue_lit` scan with the addition queue that `remove_go` already builds. - [ ] **Step 3: Implement the corner primitives**

```march
  doc "Ambient occlusion 0..3 for one face corner: two edge neighbours and the diagonal."
  @[no_alloc]
  fn corner_ao(s1 : Bool, s2 : Bool, c : Bool) : Int do
    if s1 && s2 do 0
    else 3 - ((if s1 do 1 else 0 end) + (if s2 do 1 else 0 end) + (if c do 1 else 0 end)) end
  end
```

`&&` does not short-circuit, but both operands here are already-evaluated `Bool` values with no guarded access, so the conjunct is safe.

```march
  doc "Mean skylight over the four voxels touching a face corner, skipping opaque ones."
  @[no_alloc]
  fn corner_light(ln : Int, l1 : Int, l2 : Int, lc : Int, n : Int) : Int do
    if n <= 0 do 0 else (ln + l1 + l2 + lc) / n end
  end

  doc "Pack one corner into six bits: light 0..15 in the low nibble, AO 0..3 above it."
  @[no_alloc]
  fn pack_corner(light : Int, ao : Int) : Int do light + 16 * ao end

  doc "Flip the quad's triangulation when the c0-c2 diagonal is darker than c1-c3."
  @[no_alloc]
  fn should_flip(c0 : Int, c1 : Int, c2 : Int, c3 : Int) : Bool do c0 + c2 < c1 + c3 end
```

- [ ] **Step 4: Extend `face_key` and `emit_rect`**

`face_key` currently returns the block id. It gains the light array and the chunk's integer origin, and returns `id | c0<<8 | c1<<14 | c2<<20 | c3<<26`. **The four corners must be computed in mask `(u, v)` order, not face-local order** — the axis mapping per `d` is in `emit_rect` at `mesher.march:260-286` and `fill_mask` at `:218-232`; mirror it exactly, or the decoded corners land on the wrong quad vertices.

`emit_rect` decodes the four corners straight back out of `key`, converts each to a shade with

```march

  end
```

and picks the triangulation with `should_flip`. `quad_sized` gains four shade parameters and a flip flag, emitting `(v1,v2,v3 / v1,v3,v0)` when flipped and `(v0,v1,v2 / v0,v2,v3)` otherwise.
