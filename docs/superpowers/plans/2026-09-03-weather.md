# Weather Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Overcast skies, distance fog, falling rain and snow, and a weather actor that decides when the sky turns — per `docs/superpowers/specs/2026-09-03-weather-design.md`.

**Architecture:** The vertex layout widens 8 -> 9 floats to carry a packed `effect * 256 + alpha*255` word. Two new uniforms (`u_fog_density`, `u_overcast`) let the existing fragment shader go overcast and foggy without disturbing `u_sun`, which doubles as the sun's height. A stateful particle pool in `precip.march` falls around the camera and dies on zero skylight. A `WeatherActor` in `weather.march` runs the phase machine, called once per `tick_period()`.

**Tech Stack:** March (forge), OpenGL 3.3 core via `native/cf_shim.c`, GLFW.

## Global Constraints

- Vertex layout is **9 floats**: pos.xyz, uv (2), layer, shade, face, fx. Stride 36 bytes; `a_fx` is attribute location 5 at byte offset 32.
- Effect packing is exactly `packed = float(effect * 256 + round(alpha * 255))`. Effect `0` = none, `1` = precipitation. Decode with integer ops, never fractional-part arithmetic.
- Non-precipitation geometry always pushes the literal `255.0` for `fx`.
- `u_overcast` is a separate uniform. **Never fold weather into `u_sun`** — it is the sun's height and drives the moon ramp, colour blend and dusk amount.
- Mesh slot **249** is precipitation. 250 marker, 251 icons, 252 hotbar, 253 underwater tint, 254 outline are taken.
- Env knobs added: `CF_WEATHER` (0..100, -1 = follow the actor), `CF_PRECIP` (pool capacity, default 4000). Existing frame cap is `CF_FRAMES`.
- Build cycle for every task: `forge check`, `forge build`, `forge lint --strict`, `forge test`.

- [ ] **Step 4: Write the module**

Create `lib/cube_forge/vertex.march`:

```march
-- The 9th vertex float: an effect id and an alpha packed into one number.
--
-- packed = effect * 256 + round(alpha * 255)
--
-- Floats hold integers exactly up to 2^24, so this is lossless: 16 bits of
-- effect and 8 of alpha. The obvious alternative — effect in the integer part,
-- alpha in the fraction — collides at alpha = 1.0, which is the single most
-- common value in the whole mesh. This does not.
mod CubeForge.Vertex do

  doc "Floats per vertex: pos.xyz, uv, layer, shade, face, fx."
  fn floats() : Int do 9 end

  doc "Effect: ordinary geometry, lit and fogged as usual."
  fn fx_none() : Int do 0 end
  doc "Effect: precipitation — unlit, alpha-blended, and not fogged (it is what makes the fog)."
  fn fx_precip() : Int do 1 end

  doc "Pack an effect id and an alpha 0..1 into the fx float."
  fn pack(effect : Int, alpha : Float) : Float do
    let a = if alpha < 0.0 do 0.0 else if alpha > 1.0 do 1.0 else alpha end end
    int_to_float(effect * 256 + float_to_int(a *. 255.0 +. 0.5))
  end

  doc "The effect id in a packed fx float."
  fn effect_of(p : Float) : Int do float_to_int(p +. 0.5) / 256 end

  doc "The alpha 0..1 in a packed fx float."
  fn alpha_of(p : Float) : Float do
    int_to_float(float_to_int(p +. 0.5) % 256) /. 255.0
  end

  doc "The fx value every non-precipitation vertex carries: effect 0, alpha 1."
  fn plain() : Float do 255.0 end

end
```

- [ ] **Step 1: Write the failing pool test**

Create `test/precip_test.march`:

```march
-- Precipitation pool: respawn bounds, the skylight kill, and determinism.
mod CubeForge.Test.Precip do

  needs IO.Spawn   -- capability ceiling, as in test/light_test.march
  import Test
  alias CubeForge.Precip as P
  alias CubeForge.Light as L

  -- Farthest any live particle sits from (ex, ez), horizontally.
  pfn max_radius(p : NativeFloatArr, i : Int, live : Int, ex : Float, ez : Float, worst : Float) : Float do
    if i >= live do worst
    else
      let dx = NativeArray.get_float(p, i * 4) -. ex
      let dz = NativeArray.get_float(p, i * 4 + 2) -. ez
      let d = Math.sqrt(dx *. dx +. dz *. dz)
      max_radius(p, i + 1, live, ex, ez, if d > worst do d else worst end)
    end
  end

  -- A particle sitting in a zero-skylight cell is a bug: it should have died.
  pfn first_buried(p : NativeFloatArr, la : NativeU8Arr, i : Int, live : Int) : Int do
    if i >= live do -1
    else
      let x = float_to_int(NativeArray.get_float(p, i * 4))
      let y = float_to_int(NativeArray.get_float(p, i * 4 + 1))
      let z = float_to_int(NativeArray.get_float(p, i * 4 + 2))
      if L.get(la, x, y, z) == 0 do i
      else first_buried(p, la, i + 1, live) end
    end
  end

  pfn run(p : NativeFloatArr, la : NativeU8Arr, n : Int, t : Int) : NativeFloatArr do
    if n <= 0 do p
    else run(P.step(p, 64, 64, 64.0, 80.0, 64.0, 0.016666, false, la, t), la, n - 1, t + 1)
    end
  end

  -- Fully lit sky everywhere: nothing should ever be killed. Light.new() is
  -- all-zero, which would kill every particle on its first step, so build the
  -- array directly.
  pfn open_sky() : NativeU8Arr do NativeArray.make_u8(L.volume(), L.max_level()) end

  describe "Precip.step" do
    test "keeps every particle inside the radius" do
      let p = run(P.new(64), open_sky(), 240, 0)
      Test.assert_true(max_radius(p, 0, 64, 64.0, 64.0) <= P.radius() +. 0.001, "inside the cylinder")
    end

    test "never leaves a particle in a zero-skylight cell" do
      let la = NativeArray.set_u8(open_sky(), L.index(64, 70, 64), 0)
      let p = run(P.new(64), la, 240, 0)
      Test.assert_eq_int(first_buried(p, la, 0, 64), -1, "no buried particles")
    end

    test "is deterministic for a fixed seed and tick sequence" do
      let a = run(P.new(64), open_sky(), 120, 0)
```

```march
-- Precipitation — a pool of falling particles around the camera.
--
-- A pool, not a procedural lattice: a particle with no state can only ever be
-- a falling dot. Splashes, collision and gusting all need somewhere to put
-- per-particle state, and this is that place.
--
-- Four floats per particle: x, y, z, vy. Live particles are the first `live`
-- of `cap`, so weather intensity turns the cost down by simulating fewer of
-- them rather than by making each one cheaper.
mod CubeForge.Precip do

  alias CubeForge.F32Buf as B
  alias CubeForge.Light as L
  alias CubeForge.Vertex as Vx
  alias CubeForge.Noise as N

  doc "Mesh slot for the precipitation buffer (249; 250-254 are taken)."
  fn slot() : Int do 249 end
  doc "Horizontal radius of the cylinder particles live in, in blocks."
  fn radius() : Float do 24.0 end
  doc "Height above the eye that particles respawn at."
  fn ceiling() : Float do 20.0 end
  doc "Fall speed: rain is fast and straight, snow slow and wandering."
  fn rain_speed() : Float do 28.0 end
  fn snow_speed() : Float do 2.5 end

  doc "How much of the precipitation is snow at eye height [ey]: rain below the snow line, snow above it, blended over the eight blocks beneath it. Reuses the constant that already decides where the terrain wears snow, so the weather cannot contradict the ground it lands on."
  fn snow_mix(ey : Float) : Float do
    let line = int_to_float(N.snow_line())
    if ey >= line do 1.0
    else if ey <= line -. 8.0 do 0.0
    else (ey -. (line -. 8.0)) /. 8.0 end end
  end

  -- A cheap deterministic hash: the pool must replay identically for a given
  -- seed and tick so CF_DUMP_FRAME stays meaningful.
  pfn rnd(a : Int, b : Int) : Float do N.hash2(a, b, 1337)

  pfn new_go(p : NativeFloatArr, i : Int, cap : Int) : NativeFloatArr do
    if i >= cap do p
    else
      -- Seed below the world floor so the first step respawns everything at
      -- the ceiling around wherever the camera actually is.
      new_go(NativeArray.set_float(p, i * 4 + 1, -1.0), i + 1, cap)
    end
  end

  doc "A pool of [cap] particles, all dead so the first step places them."
  fn new(cap : Int) : NativeFloatArr do
    new_go(NativeArray.make_float(cap * 4, 0.0), 0, cap)
  end

  -- Place particle [i] at a fresh point on the top of the cylinder.
  pfn respawn(p : NativeFloatArr, i : Int, ex : Float, ey : Float, ez : Float, tick : Int) : NativeFloatArr do
    let ang = rnd(i, tick) *. 6.283185307
    let rad = Math.sqrt(rnd(i + 7919, tick)) *. radius()
    let p1 = NativeArray.set_float(p, i * 4,     ex +. rad *. Math.cos(ang))
    let p2 = NativeArray.set_float(p1, i * 4 + 1, ey +. ceiling() *. rnd(i + 104729, tick))
    let p3 = NativeArray.set_float(p2, i * 4 + 2, ez +. rad *. Math.sin(ang))
    NativeArray.set_float(p3, i * 4 + 3, 0.0)
  end

  pfn step_one(p : NativeFloatArr, i : Int, ex : Float, ey : Float, ez : Float,
               dt : Float, snow : Bool, la : NativeU8Arr, tick : Int) : NativeFloatArr do
    let x = NativeArray.get_float(p, i * 4)
    let y = NativeArray.get_float(p, i * 4 + 1)
    let z = NativeArray.get_float(p, i * 4 + 2)
    let speed = if snow do snow_speed() else rain_speed() end
    -- Snow wanders sideways; rain falls straight.
    let drift = if snow do Math.sin(int_to_float(tick) *. 0.02 +. int_to_float(i)) *. 0.6 else 0.0 end
    let x1 = x +. drift *. dt
    let y1 = y -. speed *. dt
    let dx = x1 -. ex
    let dz = z -. ez
    let out = dx *. dx +. dz *. dz > radius() *. radius() || y1 < 0.0 || y1 > ey +. ceiling()
    -- The kill that matters: a cell with no skylight is under a roof, in a
    -- cave, or inside the terrain. One lookup, and rain never falls indoors.
    let sealed = L.get(la, float_to_int(x1), float_to_int(y1), float_to_int(z)) == 0
    if out || sealed do respawn(p, i, ex, ey, ez, tick)
    else
      let p1 = NativeArray.set_float(p, i * 4, x1)
      NativeArray.set_float(p1, i * 4 + 1, y1)
    end
  end

  pfn step_go(p : NativeFloatArr, i : Int, live : Int, ex : Float, ey : Float, ez : Float,
              dt : Float, snow : Bool, la : NativeU8Arr, tick : Int) : NativeFloatArr do
    if i >= live do p
    else step_go(step_one(p, i, ex, ey, ez, dt, snow, la, tick), i + 1, live, ex, ey, ez, dt, snow, la, tick)
    end
  end

  doc "Advance the first [live] particles by [dt] seconds around the eye."
  fn step(p : NativeFloatArr, cap : Int, live : Int, ex : Float, ey : Float, ez : Float,
          dt : Float, snow : Bool, la : NativeU8Arr, tick : Int) : NativeFloatArr do
    let n = if live > cap do cap else live end
    step_go(p, 0, n, ex, ey, ez, dt, snow, la, tick)
  end

  -- One camera-facing quad. Rain is a streak (tall, thin); snow is a square.
  pfn quad(b : B.F32Buf, x : Float, y : Float, z : Float, snow : Bool,
           rx : Float, rz : Float, alpha : Float) : B.F32Buf do
    let hw = if snow do 0.06 else 0.025 end
    let hh = if snow do 0.06 else 0.45 end
    let fx = Vx.pack(Vx.fx_precip(), alpha)
    -- Right vector is the camera's, flattened; up is world up, which is right
    -- for both a falling streak and a drifting flake.
    let ax = rx *. hw
    let az = rz *. hw
    let v = fn (bb, sx, sy, sz) -> bb |> B.push3(sx, sy, sz) |> B.push(0.0) |> B.push(0.0) |> B.push(0.0) |> B.push(1.0) |> B.push(0.0) |> B.push(fx)
    b |> v(x -. ax, y -. hh, z -. az) |> v(x +. ax, y -. hh, z +. az) |> v(x +. ax, y +. hh, z +. az)
      |> v(x -. ax, y -. hh, z -. az) |> v(x +. ax, y +. hh, z +. az) |> v(x -. ax, y +. hh, z -. az)
  end

  pfn build_go(b : B.F32Buf, p : NativeFloatArr, i : Int, live : Int, snow : Bool,
               ex : Float, ez : Float, rx : Float, rz : Float) : B.F32Buf do
    if i >= live do b
    else
      let x = NativeArray.get_float(p, i * 4)
      let y = NativeArray.get_float(p, i * 4 + 1)
      let z = NativeArray.get_float(p, i * 4 + 2)
      -- Fade out at the cylinder's edge so particles do not pop in and out.
      let dx = x -. ex
      let dz = z -. ez
      let d = Math.sqrt(dx *. dx +. dz *. dz) /. radius()
      let a = if d > 0.75 do (1.0 -. d) *. 4.0 else 1.0 end
      let a1 = if a < 0.0 do 0.0 else a end
      build_go(quad(b, x, y, z, snow, rx, rz, a1), p, i + 1, live, snow, ex, ez, rx, rz)
    end
  end

  doc "Rebuild [b] (cleared in place) with a camera-facing quad per live particle."
  fn build(b : B.F32Buf, p : NativeFloatArr, live : Int, snow : Bool,
           ex : Float, ey : Float, ez : Float, dx : Float, dy : Float, dz : Float) : B.F32Buf do
    -- Camera right, flattened to the horizontal plane and normalised.
    let rx0 = 0.0 -. dz
    let rz0 = dx
    let rl = Math.sqrt(rx0 *. rx0 +. rz0 *. rz0)
    let rl1 = if rl < 0.0001 do 1.0 else rl end
    build_go(B.clear(b), p, 0, live, snow, ex, ez, rx0 /. rl1, rz0 /. rl1)
  end

  fn vertex_count(b : B.F32Buf) : Int do B.len(b) / CubeForge.Vertex.floats() end

end
```

- [ ] **Step 3: Write the module**

Create `lib/cube_forge/weather.march`. The phase machine is pure and testable

```march
-- Weather — the phase machine and the actor that runs it.
--
-- Pure state: no buffers, no GL, no light field. The frame loop asks this
-- actor once per tick_period() and eases toward the answer in between, so a
-- weather change costs one message per ten frames and still looks smooth.
mod CubeForge.Weather do

  alias CubeForge.Noise as N

  doc "Phases: 0 clear, 1 cloudy, 2 rain, 3 storm."
  fn p_clear() : Int do 0 end
  fn p_cloudy() : Int do 1 end
  fn p_rain() : Int do 2 end
  fn p_storm() : Int do 3 end

  doc "How far intensity may move in one tick. The continuity property in the tests is stated against exactly this."
  fn ease_rate() : Float do 0.004 end

  doc "Target intensity for each phase."
  fn target_of(phase : Int) : Float do
    if phase == p_clear() do 0.0
    else if phase == p_cloudy() do 0.35
    else if phase == p_rain() do 0.7
    else 1.0 end end
  end

  -- phase, ticks left in this phase, current intensity, bolt level
  type Phase = Phase(Int, Int, Float, Float)

  fn start() : Phase do Phase(p_clear(), 600, 0.0, 0.0) end

  fn phase_of(s : Phase) : Int do match s do Phase(p, _, _, _) -> p end end
  fn intensity_of(s : Phase) : Float do match s do Phase(_, _, v, _) -> v end end
  fn bolt_of(s : Phase) : Float do match s do Phase(_, _, _, b) -> b end end
  doc "1 << phase, so a test can assert every phase was reached."
  fn phase_bit(s : Phase) : Int do 1 * pow2(phase_of(s)) end
  pfn pow2(n : Int) : Int do if n <= 0 do 1 else 2 * pow2(n - 1) end end

  -- Weather does not jump from clear to storm: it walks the scale, so the sky
  -- always greys before it pours.
  pfn next_phase(cur : Int, r : Float) : Int do
    if cur == p_clear() do if r < 0.7 do p_cloudy() else p_clear() end
    else if cur == p_cloudy() do if r < 0.4 do p_rain() else p_clear() end
    else if cur == p_rain() do if r < 0.35 do p_storm() else p_cloudy() end
    else p_rain() end end end
  end

  pfn dwell_for(phase : Int, r : Float) : Int do
    -- Storms are short, clear spells long. Ticks, at ten frames each.
    let base = if phase == p_storm() do 200 else if phase == p_rain() do 500 else 900 end end
    base + float_to_int(r *. int_to_float(base))
  end

  pfn clamp01(v : Float) : Float do if v < 0.0 do 0.0 else if v > 1.0 do 1.0 else v end end end

  doc "One tick of the phase machine."
  fn advance(s : Phase, tick : Int, seed : Int) : Phase do
    match s do
      Phase(phase, left, v, _) ->
        let r = N.hash2(tick, seed, 4242)
        let phase1 = if left <= 0 do next_phase(phase, r) else phase end
        let left1 = if left <= 0 do dwell_for(phase1, N.hash2(tick + 1, seed, 4242)) else left - 1 end
        -- Ease toward the target by at most ease_rate(), which is what makes
        -- the continuity property in the tests hold.
        let t = target_of(phase1)
        let d = t -. v
        let stepd = if d > ease_rate() do ease_rate() else if d < 0.0 -. ease_rate() do 0.0 -. ease_rate() else d end end
        let v1 = clamp01(v +. stepd)
        -- Lightning: only in storms, and only once the storm has built.
        let strike = phase1 == p_storm() && v1 > 0.8 && N.hash2(tick, seed, 99) < 0.02
        let b1 = if strike do 0.6 else bolt_of(s) *. 0.55 end
        Phase(phase1, left1, v1, if b1 < 0.001 do 0.0 else b1 end)
    end
  end

  -- ── The actor ────────────────────────────────────────────────────────────────
  type WxTickReq = WxTickReq

  -- Handler bodies live here (the actor lint asks handlers to delegate).
  -- Reply is [intensity * 1000, bolt * 1000, phase] -- messages carry no floats
  -- across this boundary in the shape water.march established.
  pfn handle_tick(reply_to, s : Phase, tick : Int, seed : Int) : Phase do
    let s1 = advance(s, tick, seed)
    Actor.reply(reply_to, Cons(float_to_int(intensity_of(s1) *. 1000.0),
                          Cons(float_to_int(bolt_of(s1) *. 1000.0),
                          Cons(phase_of(s1), Nil))))
    s1
  end

  actor WeatherActor do
    state { phase : Phase, tick : Int, seed : Int }
    init { phase: start(), tick: 0, seed: 1 }

    -- call handler first (tag 0): advance one tick, reply with the packed triple
    on WxTick(reply_to) do
      { state with phase: handle_tick(reply_to, state.phase, state.tick, state.seed), tick: state.tick + 1 }
    end

    on WxSeed(seed : Int) do
      { state with seed: seed }
    end
  end

  -- Message constructors are only in scope inside this module and only after
  -- the actor declaration (GAPS.md G46), so the frame loop uses these.
  fn spawn_weather() do spawn(WeatherActor) end
  fn send_seed(pid, seed : Int) : Unit do
    let _ = send(pid, WxSeed(seed))
    ()
  end
  doc "Advance the actor one tick; returns [intensity*1000, bolt*1000, phase]."
  fn call_tick(pid) : Result(List(Int), String) do Actor.call(pid, WxTickReq, 2000) end

end
```
