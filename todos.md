## Engine

- [ ] **Main-thread pinning runtime patch** (GAPS.md G15) — chip spawned, in progress in a separate session.
- [x] **Greedy meshing + sections + `blit` stdlib candidate** — done 2026-09-03 (`docs/superpowers/specs/2026-09-03-greedy-sections-blit-design.md`): 6x fewer vertices, section remesh 3–5x faster; blit exists as `cf_f32_blit` + `F32Buf.append`.
- [x] **Lighting** — done 2026-09-03 (`docs/superpowers/specs/2026-09-03-lighting-design.md`, plan `docs/superpowers/plans/2026-09-03-lighting.md`): flood-fill skylight, smooth per-vertex light + AO with quad flip packed into the greedy key, bounded incremental relight, a moving sun and moon on a 30-minute cycle with warm low-angle light and tinted moonlight (`CF_DAY`, `CF_SUN`), camera flashlight (F, `CF_FLASH`). Vertex layout 7 -> 8 floats. GAPS G63/G64.
- [x] **Dynamic shadows** — done 2026-09-03 (`docs/superpowers/specs/2026-09-03-dynamic-shadows-design.md`): voxel DDA ray-march against a 3D occupancy texture; sun, moon and flashlight all cast, reach via `CF_SHADOW_DIST` (default 64). No FBOs, no shadow maps, no depth bias.
- [x] **Weather: atmosphere, precipitation, weather actor** — done 2026-09-04 (`docs/superpowers/specs/2026-09-03-weather-design.md`, plan `docs/superpowers/plans/2026-09-03-weather.md`): vertex layout 8 -> 9 floats carrying a packed effect+alpha word, exponential fog reusing the sky colour so the two cannot disagree, `u_overcast` scaling direct light down and washing shadows out, rain and snow from a particle pool gated on zero skylight, and a `WeatherActor` walking clear->cloudy->rain->storm on `tick_period()` with lightning. `CF_WEATHER`, `CF_PRECIP`. The pool lives in the C shim, not March — see GAPS.md G67.
- [x] **Two-level shadow DDA** — done 2026-09-04: an 8x8x8 coarse occupancy level so the trace crosses open air eight blocks per fetch instead of one, with per-cell solid counts (16 KB) so a block break clears a coarse texel exactly. Skipped near the horizon (`abs(dir.y) < 0.35`), where a ray spends its whole length inside terrain and the outer walk is pure overhead — that case measured -14% before the guard. True fullscreen, soft shadows, clear weather: sun 25 93 -> 223 fps, sun 45 92 -> 181, sun 80 126 -> 123. Pixel-identical to the single-level trace at sun 12/25/80 x hard/soft and after a block break and place.
- [x] **`CF_NOMOUSE=1`** — added 2026-09-04, and it is required for any frame-dump comparison. Without it the camera yaw depends on where the window manager happened to place the window relative to the pointer, so two runs render different views. This invalidated a whole round of "regression" analysis: a dump captured early in a session differed from every later dump by 1.1M pixels, which looked like a shadow bug and was really the camera. `scratch/cmpframe.py` now also reads the BMP's real dimensions — it had 800x600 hard-coded while the dumps are 1600x1200 on a 2x display, so it silently compared a mis-sliced sub-region.

- [x] **Finite water** — done 2026-09-04. Design at `docs/superpowers/specs/2026-09-04-finite-water-design.md`: water above sea level conserves volume. A placed block is seven units that spread into a puddle and stop; id 4 stays the infinite source (the sea, and the future spring), `source_neighbour` keeps pits filling to lake level. `process` becomes push, and the reserved `kind 2` spill carries units across chunk edges with overflow bounced back rather than dropped. Found by the biome canal test, which flooded half the map. **Lands before biome phases 3-4**, or retexturing and vegetation turn every flood into a forest.
- [x] **Biomes** — done 2026-09-04, all four phases: the field and map colouring, weather by biome, budgeted surface retexturing with gravel and clay, vegetation growth and decay; bushes followed on 2026-09-04. Design at `docs/superpowers/specs/2026-09-04-biomes-design.md`: a derived, mutable climate field (temperature from a low-frequency octave minus an elevation lapse, moisture from distance to water), recomputed whole each tick because 16,384 columns is small enough that the light field's incremental machinery would be waste. Axes ease so nothing snaps; a dead band stops threshold flapping. Four phases: the field + map colouring, then weather by biome, then three new blocks with budgeted surface retexturing, then vegetation growth and decay. Unblocks the entry below.
